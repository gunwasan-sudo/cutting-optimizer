# Cutting Optimizer Pro

เว็บแอปหน้าเดียว (single-file HTML) สำหรับงานอลูมิเนียม:

- **ถอดรายการตัด (Cutting List)** จากเทมเพลตบานสำเร็จรูป — SMS Building 2 แบบ, FUJI Eurotech 32 แบบ
- **ประเมินราคา** อลูมิเนียมตามน้ำหนักที่ใช้จริง + อุปกรณ์ + กระจก + etc → ต้นทุน → ราคาขาย (ค่าแรง/ดำเนินการ/กำไร/VAT/ส่วนลด)
- **จัดเรียงตัดเส้นเต็ม (1D Bar Nesting)** พร้อม % การใช้เนื้อและใบสั่งซื้อจำนวนเส้น
- **BOM สั่งของ** รวมทั้งโครงการ แยกอลูมิเนียม (ตามเส้นเต็มที่ต้องสั่ง แยกตามแบรนด์) / อุปกรณ์ / กระจก พร้อมโหมดซ่อนราคาเวลาส่งให้ supplier
- **Export Excel** (ใบเสนอราคา / ใบสั่งซื้อ + แผนตัด / BOM สั่งของ) และสั่งพิมพ์ได้
- **บันทึกโครงการ** ลง localStorage ของเครื่อง + Export/Import ไฟล์ `.json`

## ใช้งาน

เปิดลิงก์ GitHub Pages ของ repo นี้ หรือดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์ — ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต (ไฟล์เดียวจบ รูปหน้าตัดโปรไฟล์ฝังมาในไฟล์แล้ว)

## หมายเหตุข้อมูล

- ข้อมูลโครงการเก็บไว้ในเบราว์เซอร์ของแต่ละคน (localStorage) ไม่ถูกส่งขึ้นเซิร์ฟเวอร์
- เทมเพลต FUJI ยังไม่ได้ใส่รายการอุปกรณ์ → ช่อง "อุปกรณ์" ในใบเสนอราคาจะเป็น 0
- โปรไฟล์ `B27018` (เฟรมล่างบานเลื่อน 4/5 ราง ภายใน) ยังไม่มีค่าน้ำหนัก kg/m → ไม่ถูกคิดค่าอลูมิเนียม
